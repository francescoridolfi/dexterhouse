# Retrospective

```
# Retrospective — <project>
## Numbers            (turns, iterations per task, gates and decisions, cost per phase: copied from the summary)
## What worked
## What did not       (tasks with 3 iterations and why, rejected reviews, recurring red tests)
## Lessons → actions  (table: lesson | proposed action: skill, limit, process change)
## Cost vs estimate
```

Facts first, then interpretation. A lesson without an action is a complaint: drop it or add the action.
